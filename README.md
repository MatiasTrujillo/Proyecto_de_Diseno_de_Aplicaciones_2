## Descripción del Proyecto

La solución desarrollada consiste en un Simulador de Objetos que permite modelar y ejecutar estructuras propias de la programación orientada a objetos (OOP) de forma dinámica.

Se aplicaron conocimientos de programacion y diseño de aplicaciones, como desarrollo del backend en .NET, desarrollo del frontend en Angular, uso de la metodología TDD, implementacion de una API RESTful, aplicación de los principios de paquetes, clean code, creación de diagramas de clases, entre otros.
